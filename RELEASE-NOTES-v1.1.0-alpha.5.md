# AIOS v1.1.0-alpha.5 — Autonomous Project Intelligence

This release adds the first provider-independent project-intelligence layer.

## Added
- Constitution Engine with evidence, authorization, dry-run, rollback, known-failure, production, security, and self-modification rules.
- Project Digital Twin with deterministic project fingerprints, language inventory, Python dependency discovery, and safe file limits.
- Persistent Knowledge Graph linking projects, files, dependencies, evidence, and future impact analysis.
- Wisdom Engine that ranks strategies by evidence, security, reversibility, maintainability, cost, complexity, and future value, and abstains when evidence is weak.
- Defense Intelligence Center for authorized defensive project analysis, remediation alternatives, and verification plans.
- Provider Registry keeping AIOS independent from OpenAI, Claude, Gemini, local models, or future vendors.
- Concurrent Task Orchestrator for isolated multi-topic work with failure containment.
- Persistent tables for digital twins, constitutional reviews, intelligence findings, and the knowledge graph.

## Safety model
- External or security analysis requires explicit authorization.
- The defense center reports and remediates risks; it does not exploit targets.
- High-risk actions remain subject to human approval and the alpha.4 execution safety layer.
