- Employment-state eligibility gates.
- Assignment lifecycle and persistent event ledger.
- Acceptance criteria and evidence-based completion.
- Reviewer rejection and rework workflow.
- Career success/failure integration.
- Per-worker performance history.
- Kernel exposure for phase 3.
