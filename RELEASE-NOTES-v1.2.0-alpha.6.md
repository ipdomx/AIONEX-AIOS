# AIOS v1.2.0-alpha.6 — Engineering Organization Layer

Adds a staffed digital engineering organization with specialist, senior engineer, manager, and Chief Project Engineer roles.

## Included
- Workforce and competency registry.
- Default Architecture, Backend, Frontend/Three.js, Security, Quality, DevOps, Data, and Research teams.
- Evidence-based department acceptance gates.
- Chief Project Engineer final release gate.
- Automatic rework plans when any department is incomplete.
- Persistent engineering review records.
- Extensible foundation for reputation, recruitment, worker evolution, and executive engineering councils.

## Safety and quality
The system cannot mark a project complete solely because work was generated. Every deliverable must prove all acceptance criteria, pass tests, and complete required security review before final approval.
