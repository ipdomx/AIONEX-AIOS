# AIONEX — مكان المتابعة الوحيد

المسار الحي: `/opt/AIOS/docs/project/PROJECT-REPORT.md`.

- `PLAN.json`: خريطة النطاق والدفعات ومعايير القبول وتغطية 62 قدرة، متعقبة ومراجعة في Git.
- `PROJECT-REPORT.md` و`STATE.json`: العرض الحالي المولد ذريًا من الخطة وإيصالات التشغيل. لا يعدلان يدويًا ولا يتعقبان كي لا يفسد تحديث حالة النشر نظافة source tree.
- `runtime/events.jsonl`: سجل التنفيذ الملحق ذو القفل؛ يحفظ آخر حالة دمج ونشر وتحقق وإخفاق فور حدوثها، ويجب ضمه إلى النسخ المشفرة FR-04/05. لا أسرار ولا محتوى مستخدمين.
- `SOURCE-INDEX.json`: فهرس المراجع التاريخية بالمقاسات والبصمات.
- `baseline/` و`receipts/`: توجيهات ومراجع وإيصالات مراجعة متعقبة.

اقرأ التقرير ثم STATE قبل أي عمل. أعد توليده عند اختلاف الخطة أو بعد كل إيصال:

```sh
python3 scripts/project_hub.py render --root /opt/AIOS
python3 scripts/project_hub.py validate --root /opt/AIOS
```

لتسجيل نتيجة: `python3 scripts/project_hub.py record --root /opt/AIOS --receipt <sanitized-receipt.json>`.

المدقق يتحقق من بنية الإيصال وتسلسل الاعتماد؛ المشغل مسؤول عن تحقق الأدلة الفعلية قبل تسجيلها. لا يجعل إدخال true اختبارًا حقيقيًا. يعتمد الإغلاق SHA كاملًا وفحوصًا محمية ودليل تحقق/نشر، واختبار الألف الموسع يحتاج مقاييسه كاملة.

كل دفعة مصدر تمر PR محميًا ثم تحققًا حيًا وإيصالًا؛ أي خطأ جديد يكتب هنا ولا يعاد Apply مجهول النتيجة عميانيًا. المراجع القديمة تحت docs/phase-* تاريخية ومشار إليها من هذا المكان، لا خرائط حالية مستقلة.
