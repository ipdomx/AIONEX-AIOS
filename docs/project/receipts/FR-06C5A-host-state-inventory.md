# FR-06C5A — host-state / bootstrap / swap / temporary-data inventory

Read-only inventory only. The dominant host state is historical release/audit/operator material under `/root/.config/aionex`; application secrets are small but have mixed runtime ownership. The selected 32 GiB encrypted host-state vault covers operator state and the application secret root. The no-TPM/no-KMS boot exception is reduced to one shared control-plane key plus the three currently active root-only tunnel configs so MCP2 can return before vault unlock; the TrendBost tunnel is explicitly preserved as shared control-plane state rather than being altered by the AIOS application migration. Plaintext swap is replaced later by random-key encrypted swap. `/tmp` becomes tmpfs; `/var/tmp` remains non-sensitive work scratch and is prohibited for secret/key staging.
