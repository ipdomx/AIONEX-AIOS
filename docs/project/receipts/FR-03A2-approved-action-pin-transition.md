# FR-03A2 — عقد انتقالي آمن لتحديث GitHub Actions

التاريخ: 2026-09-12

- PR576 يحدّث `anchore/sbom-action` و`aquasecurity/trivy-action` إلى SHAs كاملة جديدة، لكن اختبار Phase 34E كان يثبت SHA القديم حرفيًا فأفشل التحديث الصحيح.
- هذا الجزء لا يغير أي workflow. يوسّع عقد الاختبار إلى قائمة مغلقة من SHA الحالي وSHA الهدف المعتمد فقط، مع التحقق من 40 hex كاملة ومن workflowي Phase 34E وPhase 34F.
- لا يسمح بعلامات tags أو SHAs جزئية أو أي قيمة ثالثة.
- بعد دمج تحديث Actions نفسه يجب تنفيذ جزء تنظيف يحذف SHA القديم من القائمة المغلقة.
