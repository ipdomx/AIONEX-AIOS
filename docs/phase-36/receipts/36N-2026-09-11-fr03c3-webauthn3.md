# 36N / FR-03C3 — WebAuthn 3 passkey compatibility

The backend WebAuthn dependency is proposed to move from 2.7.0 to 3.0.0. Existing passkey service imports, generation APIs, verification signatures, configured origin-list support, and required platform/resident-key/user-verification policy remain compatible.

Local acceptance: passkey/social/migration plus the WebAuthn 3 contract tests 10/10 PASS, Core 956/956 PASS, dependency installation/check PASS, and runtime dependency audit reports no known vulnerabilities.

No production passkey, credential, database, Redis state, or infrastructure was mutated. Protected Backend CI remains mandatory before merge, and runtime deployment is deferred to the final FR-03C selective rollout.
