# دليل المالك: لوحة التحكم في AIONEX AIOS

**مكان اللوحة:** لوحة المالك على **عنوان تحكم خاص** محمي بـ Cloudflare Access. العنوان ده بيتحط في `AIOS_CONTROL_HOST` على السيرفر، و**ممنوع يتكتب في الريبو** (`PRIVATE_ORIGIN_DEPLOYMENT.md`). الرابط العام `vip-e.net` بيدّي 404 لصفحات اللوحة، وده مقصود.

**الدخول:** بحساب **Super Owner**. أي صلاحية حساسة (مختبر الأمان، وهويات الأشخاص الحقيقيين، والإعلانات) بتتمنح من هنا بس، والخادم بيتحقق منها مع كل عملية.

> كل المسارات اللي تحت جوه اللوحة (`/owner/...`). المرجع الحي لحالة الإطلاق هو `docs/project/COMPLETION-ROADMAP.md`.

## 1. الخطط والأسعار

**الخطط بتتعرّف من مكان واحد:** **البوابة** (`/owner/portal`) ← قسم الأسعار (Pricing). بعد ما تنشر (Publish)، النظام بيزامن الخطط والأسعار والحدود والمميزات لوحده مع جدول الفوترة. **مفيش كود محتاج يتغير.**

| البند | فين بيتعمل |
|---|---|
| اسم الخطة ووصفها بكل اللغات | `/owner/portal`، الأسعار |
| السعر لكل فترة (شهري أو سنوي، إلخ) | `/owner/portal`، الأسعار |
| الحدود (المشاريع، والرسائل، والتخزين، وغيرها) | `/owner/portal`، الأسعار |
| المميزات (Entitlements)، زي `3d.generation` و`security.web_scanning` وإدارة الإعلانات والأكاديمية | `/owner/portal`، الأسعار |
| الكوبونات (مبلغ ثابت أو نسبة) | **الفوترة** (`/owner/billing`) |
| منتجات متاجر الموبايل (Apple App Store وGoogle Play) | **الفوترة** (`/owner/billing`) |
| ربط الخطط بأسعار Stripe، والـ webhook، والـ Customer Portal | `STRIPE-GO-LIVE-RUNBOOK.md` (بند O-02) |

**ملاحظات:**
- **مختبر الأمان** بيتفتح لأعلى خطة تلقائيًا، يعني أغلى سعر شهري مفعّل، إلا لو حددت خطط بعينها في سياسة المختبر.
- **الحالة في 2026-11-17:** الخطة الوحيدة المفعّلة **Free**. أما **Professional** و**Business** فلسه من غير أسعار ومش مفعّلين (بند O-18).

## 3. مختبر الأمان

**المسار:** `/owner/security-lab`

| القسم | الوظيفة |
|---|---|
| Global Security Lab policy | تشغيل المختبر، والخطط المؤهلة، وحدود الأهداف والفحوصات |
| Active grants | تمنح مستخدم بعينه مستوى فحص معين، حتى لو مش على أعلى خطة |
| Registered targets / Scan profiles | الأهداف المسجلة ومستويات الفحص |
| Security evidence triage | مراجعة النتائج وقراراتك فيها |
| Security Genome & Rule Forge | القواعد المرقّاة |
| Security release gate | بوابة الإصدار الأمنية |

- **ممنوع** فحص أي هدف قبل ما صاحبه يثبت ملكيته.
- الأهداف بتاعتك (مثلًا `vip-e.net` و`ai.vip-e.net` و`api.vip-e.net`) متسجلة ومتحقق منها بالفعل (O-13).

## 4. التوليد ثلاثي الأبعاد

**المسار:** `/owner/3d`

- **تشغيل وإيقاف التوليد للمستخدمين:** حسب قرارك (O-16)، الـ 3D مقفول لحد الإطلاق.
- **إقرارات الترخيص:**
  - Hunyuan: إقرار الأهلية التجارية والاسم القانوني لمقدم الخدمة.
  - TripoSR: تفعيل البديل العالمي.
- **Hunyuan3D لسه في الحجر** (O-10)، ومحتاج قرارك. التجربة الحية نجحت (`docs/project/receipts/T13-T18-3D-LIVE-20261113.md`).
- **إعادة ضبط الـ circuits** لو المزوّد وقع أكتر من مرة.
- **تنظيف الملفات القديمة.**

**قبل الفتح للمستخدمين:**
1. اتأكد إن رصيد RunPod كفاية. الشحن التلقائي مفعّل: 25 دولار لما الرصيد يوصل 10 (O-17).
2. اطلب مننا نرفع `workersMax` للـ endpoints، لأنها دلوقتي على صفر.

## 8. أمان حسابك كمالك

- **مفاتيح المرور:** فعّلها لحسابك من الملف الشخصي.
- **الأسرار والمفاتيح:** أي مفتاح (Stripe أو Meta أو RunPod أو Docker Hub) بيتحط على السيرفر بأمر `read -rsp`، و**عمره ما بيتكتب في الشات ولا في الريبو**.
- **لو شاكك إن مفتاح اتسرب:** غيّره من موقع المزوّد، وحط الجديد بنفس الطريقة.
